# Pip Quest

A playful, game-like habit tracker: check in on daily habits, earn XP and coins, keep streak flames alive, and compare progress with friends.

**Tech:** TanStack Start, React 19, Tailwind CSS v4, Netlify (Image CDN), lucide-react.

## Run locally
```bash
pnpm install
netlify dev --port 8889
```
